🪔 등불 개인정보처리방침

시행일: 2026년 11월 14일 · 최종 갱신: 2026년 11월 19일 (구절별 녹음, 학습 기록, 외부 서비스 통신 안내 추가)

'등불'(이하 '본 앱')은 개인의 성경 묵상과 공부를 돕기 위해 제작된 개인용 학습 도구입니다. 본 앱은 사용자의 개인정보를 서버로 수집하지 않으며, 아래와 같은 원칙으로 운영됩니다.

핵심 요약 — 본 앱은 별도의 서버를 두지 않습니다. 사용자가 기록한 모든 내용(묵상 기록, 설교 기록, 음성 녹음, 구절별 내 목소리 녹음, 학습 기록, 메모 등)은 사용자의 기기 안에만 저장되며, 개발자를 포함한 그 누구도 서버를 통해 열람할 수 없습니다. 마이크는 사용자가 녹음 버튼을 누른 동안에만 사용됩니다. 사용자가 원할 경우에만, 사용자 본인의 구글 계정을 통해 구글 드라이브·구글 캘린더와 직접 연동됩니다.

2. 마이크 사용(구절별 내 목소리 녹음)

  • 마이크는 사용자가 “내 목소리 녹음”에서 녹음 버튼(●)을 눌렀을 때에만 브라우저의 권한 요청을 거쳐 사용되며, 소리는 녹음 중에만 저장됩니다. 다만 녹음 창을 여는 동안 녹음을 쉬는 중에도 마이크 연결이 유지되어 브라우저가 “마이크 사용 중” 표시를 보일 수 있으며, 녹음 창을 닫으면 마이크 연결을 해제합니다. 녹음 창에서 저장한 파일은 사용자의 기기 다운로드 폴더에 저장되며 어디로도 전송되지 않습니다.
  • 녹음 파일은 사용자의 기기 안(IndexedDB)에만 저장되고 개발자나 제3자에게 전송되지 않습니다. 이 기능은 안드로이드와 컴퓨터에서만 제공되며 아이폰에서는 제공되지 않습니다.
  • 브라우저가 저장공간이 부족하거나 사이트를 오래 사용하지 않았을 때 사이트 데이터를 삭제할 수 있습니다. 소중한 녹음은 설정의 “ZIP 내보내기”로 따로 보관하시기를 권합니다. 내보낸 파일의 보관과 삭제는 사용자의 책임입니다.
  • 녹음은 구절별 삭제, 장별 삭제, 설정의 “전체 삭제”, 또는 브라우저의 사이트 데이터 삭제로 언제든지 지울 수 있습니다.
  • 화면이 꺼져도 낭독이 이어지도록 돕는 보조 기능(무음 오디오 재생)은 소리 파일을 기기 안에서 만들어 재생할 뿐이며 어떤 정보도 수집하거나 전송하지 않습니다.

3. 구글 계정 연동(선택 사항)

사용자가 설정 화면에서 직접 "구글 드라이브 연결"을 누른 경우에만 아래 권한을 사용합니다. 연동하지 않아도 본 앱의 모든 핵심 기능(성경 읽기, 기록 작성 등)은 정상적으로 사용할 수 있습니다.

  • Google Drive (drive.file 범위) — 본 앱이 직접 생성한 백업 파일 1개(deungbul_backup.json)에만 접근합니다. 사용자의 드라이브에 있는 다른 파일에는 접근할 수 없는 권한입니다. 이 백업 파일에는 위 표에서 “구글 드라이브 백업에 포함”으로 표시된 기록(묵상, 설교, 음성 기록, 구절별 연구 노트, 캘린더 메모, 즐겨찾기, 읽음 상태, 학습 기록)의 사본이 저장됩니다. 구절별 내 목소리 녹음 파일은 포함되지 않습니다. 설정의 “내보내기”로 저장하는 백업 파일(JSON)에는 위 기록 중 음성 기록(장 단위 녹음)을 제외한 모든 기록이 들어갑니다.
  • Google Calendar (calendar.events 범위) — 사용자가 본 앱에서 생성한 일정을 사용자 본인의 구글 캘린더에 추가·조회·수정하기 위해서만 사용합니다.

이 통신은 사용자의 브라우저와 구글 서버 사이에서 직접 이루어지며, 개발자의 서버를 거치지 않습니다. 즉 개발자는 사용자가 구글과 주고받는 실제 데이터 내용을 볼 수 없습니다.

연동은 설정 화면의 "연결 해제" 버튼으로 언제든지 즉시 해제할 수 있으며, 해제 시 기기에 보관된 접근 토큰은 즉시 삭제되고 구글 계정과의 연결도 함께 취소됩니다.

4. 외부 서비스와의 통신

성경 본문(개역한글판은 대한성서공회 출처, WEB), 해설, 원어 분석 등은 앱 안에 내장되어 있어 읽기·기록·학습·녹음 기능은 인터넷 없이 동작하며 외부로 정보를 보내지 않습니다. 앱 파일 자체는 호스팅 서비스(GitHub Pages)에서 내려받으므로, 접속 시 접속 주소(IP) 등 호스팅 서비스의 일반적인 접속 기록이 해당 업체에 남을 수 있습니다. 아래는 사용자가 해당 기능을 직접 사용할 때에만 일어나는 통신입니다.

  • NIV 본문(선택): 사용자가 api.bible 키를 입력하고 [NIV]를 직접 선택한 경우에만, 보려는 구절의 위치와 입력한 키가 api.bible 서버로 전달됩니다.
  • 지도(지리 사전): 지명 상세를 열면 해당 지명이 OpenStreetMap의 검색 서비스(Nominatim)로 전달되고 OpenStreetMap 지도가 화면에 삽입되어 표시됩니다. OpenStreetMap 재단의 정책이 적용됩니다.
  • 영어 문장 클릭(Sentence X-ray): 영어 성경 문장을 누르면 그 문장이 복사되고, 같은 문장이 주소(q 값)에 담겨 Sentence X-ray 사이트(study.goodmorning0579.com)가 새 탭으로 열립니다.
  • 글꼴(컴퓨터용 파일): 컴퓨터용 파일은 화면 글꼴을 구글 폰트(Google Fonts)에서 불러오므로, 앱을 열 때 접속 주소(IP) 등 일반적인 접속 정보가 구글 서버에 전달될 수 있습니다. 사용자의 기록은 전달되지 않습니다. 모바일용 파일에서는 이 통신이 없습니다.
  • 성우 듣기(쉐도잉)·낭독: 기기에 내장된 음성 합성(TTS)을 사용합니다. 기기 설정에서 “네트워크 음성”(예: 구글 음성)을 고른 경우, 읽을 문장이 해당 음성 제공자의 서버로 전송될 수 있으며 이는 본 앱이 아니라 기기와 음성 제공자의 정책에 따릅니다. 본 앱은 읽는 내용을 별도로 수집하지 않습니다.
  • 외부 링크: 인물·지명·원어 이름 검색(구글), 원어 사전(블루레터바이블), 국어·영어 사전(네이버), 설교·찬양 검색(YouTube), 갓피아 등은 사용자가 링크를 눌러 새 창이 열릴 때 해당 사이트로 이동합니다. 검색어(이름·낱말)는 주소에 포함될 수 있으며, 이후에는 각 사이트의 정책이 적용됩니다. 본 앱이 사용자의 기록을 함께 보내지 않습니다.
  • 구글 연동: 위 3번을 참고하세요.

5. 제3자 제공 및 광고

본 앱은 사용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 광고를 표시하지 않으며, 별도의 방문 분석(애널리틱스) 도구도 사용하지 않습니다.

6. 정보의 보관 및 삭제

기기 내 로컬 저장소와 IndexedDB에 있는 정보는 사용자가 브라우저(또는 앱)의 사이트 데이터를 삭제하면 함께 삭제됩니다. 구글 드라이브에 백업된 사본은 사용자가 구글 드라이브에서 직접 삭제할 수 있고, 내보낸 파일(백업 JSON, 녹음 ZIP, 묵상 기록 문서)은 사용자의 기기에 저장되므로 보관과 삭제는 사용자의 책임입니다.

6-1. 교회·성도 관리 기능(선택 사항)

[교회·성도 관리] 기능은 이용자(교회 목회자·기관 임원 등)가 직접 입력한 성도의 이름, 연락처, 생일, 직분, 가족, 출석, 심방·기도 기록을 이용자 기기의 브라우저 저장소에만 보관합니다. 이 정보는 개발자나 외부 서버로 전송·수집되지 않으며 광고나 분석에 사용되지 않습니다.

성도의 개인정보를 입력·보관·공유하는 주체는 이용자(해당 교회)이며, 관련 법령(개인정보 보호법 등)에 따라 정보 주체의 동의를 받고 필요한 최소한의 정보만 입력해야 합니다. 이용자가 내려받은 백업·내보내기 파일에는 개인정보가 그대로 들어 있으므로 안전하게 보관하고, 다른 임원과 공유할 때는 필요한 조직의 자료만 내보내 주세요. 기능 안에서 비밀번호(6자 이상)를 설정하면 이 기기에 저장되는 성도 자료가 AES-256으로 암호화되어, 비밀번호 없이는 읽을 수 없습니다(비밀번호를 잊으면 자료를 복구할 수 없으며, 개발자도 복구할 수 없습니다). 비밀번호를 설정하지 않았거나 구형 4자리 잠금을 쓰는 경우 자료는 암호화되지 않고 화면 잠금만 적용됩니다. CSV 내보내기와 인쇄물은 암호화되지 않습니다. 브라우저 데이터를 지우면 자료가 삭제되므로 정기적인 백업을 권장합니다.
