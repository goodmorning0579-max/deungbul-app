# 🪔 등불 — 성경연구 앱 (GitHub Pages 배포용)

## 📁 폴더 구성

```
deungbul-pages/
├── index.html      ← 진입 페이지 (모바일/데스크탑 선택)
├── mobile.html      ← 모바일 버전 앱 본체
├── desktop.html      ← 데스크탑 버전 앱 본체
└── README.md      ← 이 파일
```

---

## 🚀 1단계: GitHub Pages에 배포하기

### 방법 A — GitHub 웹사이트에서 (가장 쉬움)

1. [github.com](https://github.com) 에서 새 저장소(Repository) 생성
   - 이름 예시: `deungbul-app`
   - **Public**으로 설정 (Pages 무료 사용을 위해 필요)
2. 저장소 페이지에서 **Add file → Upload files** 클릭
3. 이 폴더 안의 4개 파일(`index.html`, `mobile.html`, `desktop.html`, `README.md`)을 전부 드래그해서 업로드 → **Commit changes**
4. 저장소 상단 **Settings → Pages** 이동
5. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 설정 → **Save**
6. 1~2분 후 페이지 상단에 배포된 주소가 표시됩니다:
   ```
   https://내계정.github.io/deungbul-app/
   ```
   이 주소가 이제 앱의 정식 웹 주소입니다. 즐겨찾기 해두세요.

### 방법 B — git 명령어로 (터미널 사용 가능하신 경우)

```bash
cd deungbul-pages
git init
git add .
git commit -m "등불 앱 초기 배포"
git branch -M main
git remote add origin https://github.com/내계정/deungbul-app.git
git push -u origin main
```
이후 GitHub 저장소 → Settings → Pages에서 위 4~5번과 동일하게 설정합니다.

## ☁️ 2단계: 구글 드라이브 연동 설정 (선택사항)

기기를 바꿔도 묵상 기록이 이어지길 원하면 아래를 설정하세요. **건너뛰어도 앱 사용에는 전혀 지장 없습니다** (내보내기/가져오기 버튼으로 수동 백업은 항상 가능합니다).

### 2-1. 구글 클라우드 프로젝트 생성
1. [console.cloud.google.com](https://console.cloud.google.com) 접속 → 로그인
2. 상단 프로젝트 선택 드롭다운 → **새 프로젝트** → 이름 입력(예: `deungbul`) → 만들기

### 2-2. Google Drive API 활성화
1. 좌측 메뉴 **API 및 서비스 → 라이브러리**
2. "Google Drive API" 검색 → 클릭 → **사용(Enable)**

### 2-3. OAuth 동의 화면 설정
1. **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부(External)** 선택 → 만들기
3. 앱 이름(`등불`), 사용자 지원 이메일, 개발자 연락처만 입력하고 저장
4. **범위(Scopes)** 단계는 그냥 넘어가도 됩니다
5. **테스트 사용자** 단계에서 **본인의 구글 이메일 주소를 추가** ← 이게 핵심입니다. 이렇게 하면 구글의 앱 심사 없이 바로 사용할 수 있습니다 (본인 계정만 사용 가능)

### 2-4. OAuth 클라이언트 ID 발급
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
2. 애플리케이션 유형: **웹 애플리케이션**
3. **승인된 자바스크립트 원본**에 1단계에서 만든 GitHub Pages 주소를 정확히 입력:
   ```
   https://내계정.github.io
   ```
   (경로`/deungbul-app/`는 빼고, 도메인까지만 입력합니다)
4. **만들기** 클릭 → 생성된 **클라이언트 ID**(`xxxxx.apps.googleusercontent.com` 형식) 복사

### 2-5. 앱에 클라이언트 ID 입력
1. 배포된 앱 접속 → **설정 → ☁️ 구글 드라이브 연동**
2. 복사한 클라이언트 ID를 입력창에 붙여넣기
3. **🔗 구글 계정 연결** 클릭 → 팝업에서 로그인 (테스트 사용자로 등록한 계정 사용)
4. 이후 **☁️ 드라이브에 저장** / **⬇️ 드라이브에서 불러오기** 버튼으로 백업·복원

## ⚠️ 자주 발생하는 문제

| 증상 | 원인 / 해결 |
|---|---|
| "이 앱은 Google에서 확인하지 않았습니다" 경고가 뜸 | 테스트 앱이라 정상입니다. **고급 → (앱이름)로 이동(안전하지 않음)** 클릭 후 계속 진행하세요. 본인만 쓰는 개인 앱이므로 문제 없습니다. |
| 구글 로그인 버튼을 눌러도 반응 없음 | `file://`로 파일을 직접 열었을 가능성이 높습니다. 반드시 `https://내계정.github.io/...` 주소로 접속해야 합니다. |
| "승인되지 않은 origin" 오류 | 2-4단계에서 입력한 자바스크립트 원본 주소가 실제 접속 주소와 정확히 일치하는지 확인하세요 (끝에 슬래시(`/`) 유무 등). |
| 앱 내용을 수정했는데 반영이 안 됨 | GitHub에 새로 업로드(커밋)한 후 1~2분 정도 기다려야 Pages에 반영됩니다. 브라우저 강력 새로고침(Ctrl/Cmd+Shift+R)도 시도해보세요. |

## 📱 홈 화면에 앱처럼 설치하기 (PWA)

GitHub Pages로 배포한 뒤에는 브라우저 탭이 아니라 **아이콘을 탭해서 여는 앱처럼** 설치할 수 있습니다.

### 아이폰 (Safari)
1. 배포된 주소로 접속 (예: `https://내계정.github.io/deungbul-app/mobile.html`)
2. 하단 공유 버튼(⬆️) 탭 → **"홈 화면에 추가"**
3. 홈 화면에 🪔 등불 아이콘이 생기며, 탭하면 주소창 없이 전체화면 앱처럼 열립니다

### 안드로이드 (Chrome)
1. 배포된 주소로 접속
2. 우측 상단 메뉴(⋮) → **"앱 설치"** 또는 **"홈 화면에 추가"**
3. 자동으로 설치 안내 배너가 뜨기도 합니다

### PC (Chrome/Edge)
1. `desktop.html` 주소로 접속
2. 주소창 오른쪽의 **설치 아이콘**(⊕ 또는 화면 모양) 클릭 → 설치
3. 독립 실행형 앱 창으로 열리며, 작업표시줄/독에 고정 가능

설치 후에는 오프라인에서도 이전에 열어본 화면 일부가 캐시되어 표시됩니다(완전한 오프라인 지원은 아니며, 실시간 성경 본문 API는 인터넷 연결이 필요합니다).

## 🚀 진짜 "설치 버튼"이 작동하게 하기 — GitHub Pages 없이, 파이썬 없이!

앱 안의 "📲 지금 설치하기" 버튼은 `file://`(파일 직접 열기)에서는 브라우저 정책상 작동하지 않습니다. GitHub Pages 배포도 원하지 않고 파이썬도 없으시다면, **Windows에 이미 내장된 PowerShell**로 해결할 수 있습니다. 별도 설치가 전혀 필요 없습니다.

### 사용법 (딱 한 번만 설정하면 계속 재사용 가능)
1. `mobile.html`(또는 `desktop.html`), `등불_실행하기.bat`, `등불_로컬서버.ps1`을 **모두 같은 폴더**에 두세요
2. **`등불_실행하기.bat`**를 더블클릭하세요
3. 검은 콘솔 창이 뜨고 잠시 후 브라우저가 자동으로 열립니다 (`http://localhost:8080`)
4. 이 상태에서는 설정 화면의 **"📲 지금 설치하기" 버튼이 진짜로 작동**합니다 — 클릭 한 번으로 설치 완료!
5. 설치가 끝나면 콘솔 창은 닫으셔도 됩니다 (설치된 앱은 그대로 유지됩니다)

### 다음에 또 쓰려면?
`등불_실행하기.bat`을 다시 더블클릭하기만 하면 됩니다. 이미 설치되어 있다면 서버를 켤 필요 없이 바로 설치된 앱 아이콘을 쓰시면 됩니다.

### 참고
- 콘솔 창에 "Windows Defender 방화벽에서 이 앱을 차단했습니다" 같은 경고가 뜨면 **"액세스 허용"**을 눌러주세요 (내 컴퓨터 안에서만 열리는 서버라 외부에서는 접근할 수 없습니다)
- 8080 포트가 이미 사용 중이라는 오류가 뜨면, `등불_로컬서버.ps1` 파일을 메모장으로 열어 `$port = 8080`을 `$port = 8090` 등으로 바꿔보세요

## 🖥️ PC 바로가기 아이콘 만들기 (배포 없이 로컬 파일로도 가능)

### Windows — 자동 스크립트
1. 등불 HTML 파일을 원하는 위치(예: 다운로드 폴더)에 저장해두세요
2. 이 폴더의 **`등불_바로가기_만들기.vbs`** 파일을 더블클릭
3. 안내창에 등불 HTML 파일의 전체 경로를 입력 (파일 우클릭 → "경로로 복사"로 붙여넣기 가능)
4. 바탕화면에 🪔 아이콘의 "등불" 바로가기가 자동 생성됩니다

### Mac — `Mac_바로가기_가이드.md` 참고
Automator로 전용 아이콘이 적용된 앱을 만들거나, 간단히 Dock에 드래그하는 방법을 안내합니다.

### 브라우저 탭 아이콘 (파비콘)
`mobile.html`/`desktop.html`은 어떻게 열어도 브라우저 탭에 🪔 아이콘이 자동 표시됩니다 (파일에 내장되어 있어 별도 설정 불필요).
